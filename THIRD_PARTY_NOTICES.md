## Data sources

* Network exposure uses the John Snow Soho cholera data distributed with the
  PySAL / GeoDa example data collection.
* Multiscale education uses the Georgia county dataset distributed with
  `libpysal` and the accompanying GWR4 reference output.
* Spatial generalization uses the Meuse dataset distributed with the R `sp`
  package; the workflow retrieves the original CRAN package data files.
